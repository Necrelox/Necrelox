Necrelox · cinq pistes de portfolio terminal

Les projets affichés sont des exemples, à remplacer par les tiens.

Ce qui se fait sur GitHub

Le shell interactif

Le format le plus courant : le visiteur tape help, projects, contact. Voir terminal-portfolio, CmdFolio, TermFolio. Les meilleurs ajoutent des raccourcis cliquables et des thèmes.

La carte fetch

Un logo ASCII à gauche, les infos à droite, comme neofetch ou fastfetch. Voir le thème Astro astro-distro, qui synchronise aussi les projets depuis GitHub.

Le README de profil

Sans site : un GIF de terminal généré pour le README, avec github-readme-terminal, ou des stats en ASCII. Bon complément au portfolio.

L'animation ASCII

GitHub a détaillé la fabrication de la bannière ASCII animée de Copilot CLI. Même principe ici : on dessine dans un canvas caché, puis on convertit les pixels en caractères.

Le portfolio dans le vrai terminal

Certains vont jusqu'à un portfolio lancé avec npx, voir own-term. Amusant, mais peu de visiteurs le lanceront.

Pour démarrer

freeCodeCamp a un tutoriel complet. Une seule page HTML suffit, hébergée gratuitement sur GitHub Pages.
